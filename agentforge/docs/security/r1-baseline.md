# Release 1 security baseline: evidence

The baseline is defined in the architecture document, §13.6. Every item must have evidence
before R1 ships or is demonstrated live. Test paths are relative to `apps/server/tests/`
(Python) or `apps/web/` (browser and unit tests). Every listed test runs in CI on every push
to `feature/dev`. The last green run before this document was
[39309240357](https://github.com/Kingslee1604/2026AIProjects/actions/runs/39309240357)
(commit 34ec1fe). The commit that adds this document adds the tests marked *(R1-46)*.

Status (2026-10-19): **14 of 15 items have evidence; S15 does not apply yet.** There is no
public replay in R1 for now, because R1-47 was deferred. S15 must pass before a replay is
deployed. R1-46 found four gaps and closed them: S1's bind rule, S6's egress test, the S8 limits
on uploads, questions and runs, and S11's log scan.
